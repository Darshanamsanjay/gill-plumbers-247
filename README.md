# Gill Plumbers 247

Professional, high-performance 24/7 emergency plumbing, heating, and drainage website for Wolstanton and Birmingham.

## Features

- **Modern Visual Identity**: Alternating visual environments (deep navy, ice, and clean technical white) with kinetic typography watermarks.
- **Interactive Service Canvas**: Quadrant selector for General Plumbing, Gas Safe Heating, Drainage, and Acoustic Leak Detection.
- **24/7 Emergency Dispatch Radar**: Luminous emergency beacon with instant call actions.
- **Diagnostic Situation Finder**: Step-by-step issue routing for domestic and commercial plumbing breakdowns.
- **"Follow the Flow" Backbone**: Dynamic scroll-linked fluid indicator connecting narrative sections to direct dispatch.
- **Fully Responsive & Accessible**: Built with semantic HTML5, fluid responsive typography, and screen-reader accessibility.

## Tech Stack

- **Core**: Vanilla HTML5 / CSS3 / JavaScript (Zero framework overhead, lightning fast)
- **Typography**: Space Grotesk & Plus Jakarta Sans via Google Fonts
- **Icons & Graphics**: Pure inline SVG with hardware-accelerated CSS animations

## Service Coverage

- **Primary Depot**: ST5 0HE, Wolstanton, Newcastle-under-Lyme
- **Midlands Hub**: Greater Birmingham & West Midlands
